# Shorts Detection: 
Identifies YouTube Shorts using #Shorts hashtag detection in the title or description, or a video duration between 1 and 60 seconds. This is a heuristic, as YouTube Data API v3 does not provide a dedicated Shorts identifier.

# Architecture & Implementation Decisions:

The project follows MVVM with Clean Architecture principles,
separating Presentation, 
Domain, and Data layers 
to ensure maintainability, scalability, and testability.

The architecture documentation explains the main components,
data flow, dependency injection, API integration, local caching, pagination, 
and key implementation decisions, including the reasoning behind technology choices 
and trade-offs.
